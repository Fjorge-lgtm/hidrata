Política de Privacidade — Hidrata

Última atualização: 20/09/2026

O Hidrata é um aplicativo de lembrete para beber água, desenvolvido por Francisco Jorge Pires Jácome / fluxoteca, CNPJ 68.520.569/0001-11.

1. Dados coletados

O Hidrata não coleta dados pessoais nem qualquer outro dado do usuário. Os horários e as configurações dos lembretes ficam armazenados apenas no seu dispositivo e não são enviados a nenhum servidor.

2. Permissões

O app usa as permissões de notificações e de alarmes para avisar você nos horários configurados. Essas permissões não são usadas para coletar informações.

3. Compartilhamento

Não compartilhamos dados com terceiros.

4. Compra do aplicativo

O Hidrata é um aplicativo pago, e a compra é processada pelo Google Play. Não temos acesso aos seus dados de pagamento.

5. Seus direitos (LGPD)

Como os dados do app ficam apenas no seu dispositivo, você pode apagá-los a qualquer momento limpando os dados do app ou desinstalando-o. Para solicitar acesso, correção ou exclusão de dados, ou para tirar dúvidas sobre a LGPD, escreva para fjorge.pjacome@uol.com.br.

6. Alterações

Esta política pode ser atualizada. A data no topo da página indica a versão atual.
